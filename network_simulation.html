ATTACK CHAIN & DEFENCE REFERENCE
⚠ ATTACK CHAIN
1
Initial Compromise
Phishing email opened on ANDROID-01 (guest network). Macro payload executes — reverse shell established to attacker C2 server on port 443, disguised as HTTPS traffic.
2
Guest Network Scanning
Attacker scans VLAN40 subnet (10.0.40.0/24). ARP poisoning initiated — guest traffic intercepted. AP-01 exploited as pivot point toward the firewall.
3
Firewall Bypass
CVE-2023-27997 (Fortinet heap overflow) exploited on unpatched firewall. VLAN40→VLAN20 ACL rules bypassed. Guest network can now reach corporate network — VLAN isolation broken.
4
Lateral Movement
EternalBlue-style SMB exploit compromises WS-R01. Credential hashes harvested. Pass-the-hash attack on WS-R02 — no new exploit needed. Attacker is now inside the corporate LAN.
5
Worm Propagation
Self-propagating worm spreads across VLAN20 via SMB (port 445) and RDP (port 3389). All 10 workstations and both meeting room displays compromised. Keyloggers and persistence deployed.
6
Infrastructure Takeover
Harvested admin credentials used to access core switch management interface. Port mirroring enabled — all VLAN traffic copied to attacker. All APs reconfigured, rogue SSIDs injected.
7
Server Compromise
DNS poisoning initiated. Email/file server SMB shares accessed — ransomware payload dropped. Active Directory DCSync attack extracts all domain password hashes. Full domain compromise.
8
Perimeter Hijack
AD Group Policy used to push malicious config to router. Both WAN links (fibre + 4G) hijacked. All outbound traffic routed through C2. Ransomware deploys network-wide via Group Policy.
✓ DEFENCE CONTROLS
Blocks Stage 2
Network Monitoring (IDS/IPS)
Detects ARP poisoning and port scanning on guest subnet. IPS auto-isolates ANDROID-01. Attack chain terminated before reaching the firewall. Note: IDS alone only alerts — IPS enforcement is required to auto-block.
Blocks Stage 3
Patched Firewall
CVE-2023-27997 is patched. Heap overflow exploit fails. VLAN40→VLAN20 ACL rules hold firm. Attacker cannot cross from guest network into corporate network regardless of guest device compromise.
Blocks Stage 4
Multi-Factor Authentication (MFA)
Harvested password hashes are useless without the physical second factor. Pass-the-hash attacks fail. Lateral movement into the corporate workstation estate is impossible even with valid credentials.
Blocks Stage 5
Endpoint Detection & Response (EDR)
EDR detects worm payload on first endpoint, terminates the process and auto-isolates the machine. Propagation to remaining 9 workstations and displays is prevented in real time.
Blocks Stage 6
Least Privilege & Admin Tiering
Switch management requires separate tier-0 admin credentials never cached on workstations. Harvested domain user credentials have no switch or AP access. Network infrastructure remains under IT control.
Limits Stage 8
Offline / Immutable Backups
Attack achieves full compromise — but ransomware has no leverage. Offline or WORM-protected backups cannot be encrypted or deleted. Organisation recovers without paying ransom. Estimated RTO: 4–8 hours vs weeks without backups.

LNS Corporate Network Simulation
Interactive Network Simulation — Educational Tool
⚠ DISCLAIMER — EDUCATIONAL USE ONLY
This tool is a simulated network environment built for learning purposes. All devices, IP addresses, network topology and attack scenarios are entirely fictional. No real network traffic is generated. CVE references are cited for educational context only — this tool does not exploit, replicate or assist in exploiting any real vulnerability. The attack simulation is designed to teach defensive security concepts, not to facilitate or encourage malicious activity. Do not attempt to replicate any attack techniques demonstrated here against real systems.
WHAT IS THIS?
An interactive corporate network diagram built as a self-directed learning tool. It visualises a realistic two-site network — a headquarters and branch office — including VLANs, routing, DHCP, wireless infrastructure, and a site-to-site VPN. Everything is interactive: click any device to inspect it, run failure scenarios, watch DHCP leases allocate and expire, and simulate a full cyberattack from initial phishing email to domain compromise.
WHAT YOU CAN LEARN
Networking Concepts

DHCP pools, lease allocation and APIPA

Security Concepts

Why MFA, EDR and patching matter
Full vs split tunnel VPN security implications
HOW TO USE
Click any device to inspect its IP, MAC, VLAN, status and technical details in the right panel.
Failures tab — trigger network fault scenarios: firewall block, switch port down, DHCP exhaustion, router failover.
Defence tab — enable security controls before running the attack to see which stages get blocked and why.
Simulate Attack — runs a staged phishing attack from guest device to full domain compromise (~60 seconds at normal speed).
Explain Attack — reference panel showing the full attack chain and corresponding defence controls side by side.
VPN toggle — switch between full tunnel and split tunnel to see how it affects attack propagation to Site 2.
Sim Speed — accelerate the simulation to see DHCP lease expiry, uptime counters and traffic at faster rates.
